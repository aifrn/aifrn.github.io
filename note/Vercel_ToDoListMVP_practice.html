1단계: 준비하기

필요한 계정 (모두 무료)

1) GitHub - 용도: 코드를 보관하는 곳 - 가입 주소: https://github.com 2) Vercel - 용도: 웹사이트를 인터넷에 올려주는 곳 - 가입 주소: https://vercel.com [팁] Vercel 가입 시 "Continue with GitHub" 버튼으로 가입하면 두 서비스가 자동으로 연결되어 편합니다.

필요한 프로그램

1) Git - 용도: 코드 변경 기록, 업로드 - 설치 확인 명령어: git --version 2) Claude Code - 용도: AI에게 말로 코딩 요청 - 설치 확인 명령어: claude --version 3) GitHub CLI (선택) - 용도: 터미널에서 GitHub 저장소 만들기 - 설치 확인 명령어: gh --version 참고: Node.js나 Vercel CLI는 이번 강의에서는 필요 없습니다. (HTML 파일 하나만 배포하기 때문)

명령 프롬프트(cmd) 여는 법

이 강의의 모든 명령어는 명령 프롬프트(cmd) 기준입니다. Visual Studio Code 의 터미널을 하나 추가합니다. 혹은 아래 방법을 사용합니다. 1. 키보드에서 Windows 키 + R 누르기 2. cmd 입력 후 Enter 3. 검은 창이 열리면 준비 완료! 또는 시작 메뉴에서 "명령 프롬프트"를 검색해도 됩니다.

설치 확인하기 (PASS)

명령 프롬프트(cmd)에 아래를 입력합니다.
git --version
gh --version
버전 번호가 나오면 설치된 것입니다. 강의 준비 시 실제 확인 결과:
git version 2.56.0.windows.4
gh version 2.103.3

GitHub CLI 로그인 (선택)

GitHub CLI를 쓰려면 한 번 로그인해야 합니다.
gh auth login
화면 안내에 따라 GitHub.com -> HTTPS -> Login with a web browser 를 선택하면 브라우저가 열리고 로그인됩니다. 로그인 확인:
gh auth status

작업 폴더 만들기

mkdir C:\dev\VercelIntro
cd C:\dev\VercelIntro
마지막 Claude Code 를 실행합니다. 비주얼스튜디오코드를 실행한 후 터미널에서 `claude` 명령으로 Claude code 를 실행합니다. 이제 다음 단계로!
2단계: Claude Code로 할일 앱 만들기

Claude Code에게 요청하기

Claude Code 화면에 아래처럼 한국어로 요청합니다. (실제 강의 준비 때 사용한 프롬프트)
vercel 서비스를 이용하는 간단한 웹앱을 만들어본다.
최소 기능을 가진 할일 관리앱을 만들어줘.
"할일 관리앱"의 제목(TITLE)은 "나의 할일 목록"이고, 문자열 입력을 받는 창이 하나 있고, [추가]버튼이 있다. 
이미 할일이 있는 경우 왼쪽에 체크박스와 오른쪽에 [삭제] 버튼이 있다.
최소 기능으로 동작한다. 
HTML + CSS + JS 이렇게 3개 내용을 index.html 파일 하나 안에 작성한다. 
DB는 사용하지 않고, 브라우저의 localStorage 를 사용한다. 
배포는 GitHub 연동방식을 이용한다.

Claude가 물어본 질문과 선택한 답

Claude는 만들기 전에 몇가지 선택지를 줍니다. 모두 클로드가 추천하는 쪽을 고릅니다. 질문 1) 어떤 기술로 만들까? - 선택지: HTML+JS 한 파일 / Next.js - 선택: HTML+JS 한 파일 - 이유: 설치, 빌드 없음. 파일 1개 질문 2) 데이터는 어디에 저장? - 선택지: 브라우저 localStorage / 서버 DB - 선택: localStorage - 이유: 추가 설정 0 질문 3) 배포 방법은? - 선택지: GitHub 연동 / Vercel CLI - 선택: GitHub 연동 - 이유: 클릭 위주, 자동 배포를 보여주기 좋음

만들어진 결과: index.html

파일 하나에 세 부분이 들어 있습니다. 1) HTML - 역할: 화면에 무엇이 있는지 (제목, 입력창, 버튼, 목록) - 비유: 집의 뼈대 2) CSS (<style> 부분) - 역할: 어떻게 보이는지 (색, 크기, 배치) - 비유: 인테리어 3) JavaScript (<script> 부분) - 역할: 버튼을 누르면 무슨 일이 일어나는지 - 비유: 전기, 수도

핵심 동작 원리 (코드를 몰라도 OK)

1. 입력창에 글을 쓰고 "추가"를 누르면 -> 목록에 넣고 -> 브라우저에 저장 2. 체크박스를 누르면 -> 완료 표시(줄 긋기) -> 저장 3. "삭제"를 누르면 -> 목록에서 빼고 -> 저장 4. 페이지를 새로 열면 -> 브라우저에 저장된 목록을 불러와서 표시 localStorage는 각자의 브라우저에 저장된다. 휴대폰에서 추가한 할일은 PC에서는 안 보인다. (최소 기능이므로 OK)

내 컴퓨터에서 먼저 확인하기

배포하기 전에 내 컴퓨터에서 동작을 확인합니다. 명령 프롬프트(cmd)에서 프로젝트 폴더로 이동한 뒤 실행합니다. 터미널의 (+) 키를 눌러 새로운 터미널을 추가한 다음 새로 만들어진 터미널에서 아래 명령을 실행한다. 기존 첫번째 터미널은 클로드코드 실행중이고, 두번째 터미널에서 PC 의 명령을 실행한다.
start index.html
(또는 파일 탐색기에서 index.html을 더블클릭) 브라우저가 열리면 할일을 추가, 체크, 삭제해 보세요. 이 상태는 아직 나만 볼 수 있습니다.
3단계: GitHub에 코드 올리기
Vercel은 GitHub에 있는 코드를 가져가서 배포합니다. 그래서 먼저 GitHub에 올립니다.

용어 정리

- Git 파일의 변경 기록을 저장하는 프로그램 (게임의 "세이브" 같은 것) - commit (커밋) 현재 상태를 세이브하는 것 - GitHub 세이브 파일을 인터넷에 보관하는 곳 - repository (저장소, repo) GitHub에 있는 프로젝트 폴더 하나 - push (푸시) 내 컴퓨터의 커밋을 GitHub로 올리는 것

방법 A: Claude Code에게 맡기기 (강의 시연 방식)

Claude Code에 이렇게 요청하면 됩니다.
GitHub에 "vercel-todo-app" 이름으로 public 저장소를 만들어서 코드를 올려줘
Claude Code가 실제로 실행한 명령어를 명령 프롬프트(cmd) 기준으로 정리하면 아래와 같습니다. [팁] cmd에서 REM으로 시작하는 줄은 설명(주석)이라 실행되지 않습니다. 입력하지 않아도 됩니다.
REM 1) 이 폴더를 Git 저장소로 만들기 (처음 한 번만)
git init -b main

REM 2) 올릴 파일 선택하고 세이브(커밋)
git add .
git commit -m "할일 관리 앱 첫 버전"

REM 3) GitHub에 저장소를 만들고 바로 올리기 (GitHub CLI 사용)
gh repo create vercel-todo-app --public --source=. --push

방법 B: 직접 웹사이트에서 하기 (GitHub CLI가 없을 때)

1. https://github.com/new 접속 2. Repository name: vercel-todo-app 입력 3. Public 선택 -> Create repository 클릭 4. 화면에 나오는 안내 중 "...or push an existing repository" 부분의 명령어를 복사해서 터미널에 붙여넣기
git remote add origin https://github.com/<내아이디>/vercel-todo-app.git
git push -u origin main

확인

https://github.com/<내아이디>/vercel-todo-app 에 들어가서 index.html이 보이면 성공!
4단계: Vercel로 배포하기 (*핵심*)
드디어 핵심입니다. 명령어 없이 웹 화면에서 클릭만으로 진행합니다.

4-1. Vercel 로그인

1. https://vercel.com 접속 2. Sign Up (처음) 또는 Log In 클릭 3. Continue with GitHub 선택 -> GitHub 권한 허용 참고: 처음 가입하면 플랜을 물어봅니다. Hobby (무료)를 선택하세요.

4-2. 프로젝트 가져오기 (Import)

1. 대시보드 오른쪽 위 Add New... -> Project 클릭 2. Import Git Repository 목록에서 vercel-todo-app 옆의 Import 클릭 - 목록에 안 보이면: Adjust GitHub App Permissions 클릭 -> 저장소 접근 허용

4-3. 설정 확인 후 배포

설정 화면이 나오면 아무것도 바꾸지 않습니다. 각 항목의 값은 다음과 같습니다. - Project Name: vercel-todo-app 주소에 사용될 이름 - Framework Preset: Other 프레임워크 없음 (HTML 파일만 있으므로) - Root Directory: ./ 그대로 - Build Command 등: 비워둠 빌드할 것이 없음 Deploy 버튼 클릭!

4-4. 배포 완료!

10~30초 후 축하 화면(Congratulations!)이 나옵니다. - Continue to Dashboard 클릭 - Domains 에 표시된 주소가 내 앱의 인터넷 주소입니다. - 예: https://vercel-todo-app.vercel.app - (이름이 이미 사용 중이면 vercel-todo-app-xxxx.vercel.app 처럼 뒤에 글자가 붙습니다) 이 주소를 휴대폰에서 열어보세요. 전 세계 어디서나 접속됩니다!

이번 강의 샘플의 실제 배포 주소

(배포 후 여기에 기록)

Vercel 대시보드 둘러보기

- Deployments 지금까지 배포한 기록 목록. 예전 버전으로 되돌리기도 가능 - Domains 접속 주소 관리 (내 도메인 연결도 가능) - Analytics 방문자 통계 (켜야 동작) - Settings 프로젝트 이름, Git 연결 등 설정
5단계: 코드 수정 -> 자동 배포 확인
Vercel + GitHub 연동의 진짜 장점: GitHub에 올리기만 하면 사이트가 자동으로 바뀝니다.
코드 수정 -> git push -> (Vercel이 자동 감지) -> 약 10초 후 사이트 반영

실습: 제목 바꿔보기

1) Claude Code에게 수정 요청
앱 제목을 "To Do List"로 바꾸고 GitHub에 올려줘
2) Claude Code가 하는 일 1. index.html의 제목 부분 수정 2. 아래 명령어 실행 (cmd 기준)
git add .
git commit -m "앱 제목 변경"
git push
3) Vercel에서 확인 (Option) 1. Vercel 대시보드 -> 프로젝트 -> Deployments 탭 2. 새 배포가 Building -> Ready 로 바뀌는 것을 확인 3. 내 앱 주소를 새로고침 -> 제목이 바뀐 것 확인! [강의 포인트] 우리는 Vercel에 아무것도 하지 않았습니다. git push만 했을 뿐인데 사이트가 바뀌었습니다. 이것이 자동 배포(CI/CD)입니다.

실수했을 때: 이전 버전으로 되돌리기

1. Deployments 탭에서 예전 배포 항목 오른쪽 ... 버튼 클릭 2. Promote to Production (또는 Instant Rollback) 선택 3. 즉시 예전 버전으로 돌아갑니다.

정리

- Vercel 웹사이트를 인터넷에 무료로 올려주는 서비스 - GitHub 연동 한 번 연결하면 push할 때마다 자동 배포 - 배포 주소 https://프로젝트이름.vercel.app - 롤백 Deployments에서 클릭 한 번으로 예전 버전 복구

더 해볼 수 있는 것 (심화)

- 내 도메인 연결하기 (Settings -> Domains) - Vercel Analytics로 방문자 수 보기 - 서버 DB를 연결해서 여러 기기에서 같은 할일 보기 (Vercel Marketplace -> 데이터베이스)
